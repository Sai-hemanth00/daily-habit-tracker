# Daily-Habit-Tracer

A clean and modern Daily Habit Tracker Web Application built using HTML, CSS, and JavaScript.
This project helps users build consistency by tracking daily habits, marking completion, and maintaining streaks.

🚀 Live Demo
🔗 https://sai-hemanth00.github.io/daily-habit-tracker/

✨ Features
➕ Add new habits
✅ Mark habits as completed
🔥 Streak counter system
❌ Delete habits
🎨 Clean and modern UI
📱 Responsive layout
🌐 Deployed using GitHub Pages
🛠️ Tech Stack
HTML5 – Structure
CSS3 – Styling & layout
JavaScript (Vanilla JS) – Logic & interactivity
Git – Version control
GitHub – Repository hosting
GitHub Pages – Deployment

📂 Project Structure
daily-habit-tracker/
├── index.html
├── script.js
├── style.css
└── README.md

🧠 How It Works:
User adds habits
Daily completion is tracked using checkboxes
Streak count increases on completion
Habits can be deleted
UI updates dynamically using JavaScript
